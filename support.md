# Support

## Reporting a bug or requesting a feature

This documentation site is backed by a **public GitHub repository that doubles as the
issue tracker** for Latte+. If something doesn't work or you'd like to see a feature,
open an issue:

- 🐞 **[Report a bug](https://github.com/zipper/latte-plus-docs/issues/new?template=bug_report.yml)**
- 💡 **[Request a feature](https://github.com/zipper/latte-plus-docs/issues/new?template=feature_request.yml)**
- 📋 **[Browse existing issues](https://github.com/zipper/latte-plus-docs/issues)**

## What to include in a bug report

A good report gets fixed faster. Please include:

1. **PhpStorm version** and **Latte+ version**
   (Help → About / Settings → Plugins → Latte+).
2. **Operating system.**
3. A **minimal `.latte` snippet** that reproduces the problem.
4. **What you expected** vs. **what happened** (a screenshot of incorrect
   highlighting, a wrong/missing completion, or a false inspection is very helpful).
5. If relevant, your **Latte / Nette version**.

The bug-report template walks you through these fields.

## Before reporting

- Check the [Known limitations](./limitations.html) page – the behavior may be a
  documented edge case.
- Make sure no **other Latte plugin** is enabled at the same time
  (see [Installation](./installation.html)).
- Try the latest version – the issue may already be fixed.
